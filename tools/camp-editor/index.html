Identity

The leash is the Chebyshev radius around the camp's spawn tile that PASSIVE members wander within — a hostile member pursuing may leave it. Camp units drip-spawn through the spawn tile one per slot, so a tight pocket works.

Units (combatant archetypes, spawned onto team neutral)

Count and level default to 1 when blank (a bare entry saves bare). Only combatant archetypes are listed — a camp unit is a regular combatant def on team: 'neutral'; walls/rubble can't be camp members.

Rewards (rolled when the player kills the whole camp)

Each row references a table in config/rewards.json by name (author tables in the reward table editor); when the camp is killed by the player, every ref's chance is tested independently and a passing table is sampled once — granted at turn completion win-or-lose (the 51a portion rule). No rows = the rewards key is omitted (the camp pays nothing).

Validation

    Runs the SAME CampsSchema the game boots on, plus both boot asserts: every reward ref must name a real table, and every committed layout's camps[].campId must still resolve here (renaming or deleting a camp a layout references blocks Save — fix the layout first).
